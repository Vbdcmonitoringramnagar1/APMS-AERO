Data management

This prototype stores data in this browser's local storage. It does not yet sync across devices or provide secure multi-user login. Firebase Authentication and Firestore must be configured before official deployment.

Do not use this local prototype as the official system for live voter data until authentication, role-based access, server-side validation, audit logs, secure backups and an approved hosting environment are implemented. Share applicant data only with authorised personnel.
